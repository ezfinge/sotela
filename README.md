# 🖥️ sotela

Serviço de compartilhamento de tela com áudio, estilo Discord, sem necessidade de registro.

## ✨ Funcionalidades

- 🖥️ Compartilhamento de tela com áudio
- 🏠 Servidores e canais
- 🔗 Convites via link
- 👥 Múltiplos participantes
- 🎯 Sem cadastro necessário

## 🚀 Como Usar

### Instalação

\`\`\`bash
# Clone o repositório
git clone https://github.com/SEU_USUARIO/screenshare.git

# Entre na pasta
cd screenshare

# Instale as dependências
npm install

# Inicie o servidor
npm start
\`\`\`

### Acessar

Abra `http://localhost:3000` no navegador

## 🛠️ Tecnologias

- Node.js
- Express
- Socket.IO
- WebRTC
- HTML5
- CSS3
